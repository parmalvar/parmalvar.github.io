# parmalvar.github.io

Academic homepage for Parniyan Malekzadeh:
https://parmalvar.github.io/

## Stack

Static HTML, CSS, and JavaScript hosted on GitHub Pages. No Jekyll and no build step.

## Local preview

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000/`.

## CV

The public CV is stored at:

`files/Parniyan_Malekzadeh_CV.pdf`

The PDF is a copied export from the CV source project. This website repository is not the source of truth for the CV. When the CV is updated, replace the PDF while preserving the same filename and URL.

## Assets

The portrait is stored at `assets/portrait.jpg`.
Self-hosted fonts are under `assets/fonts/`; licensing information is in `assets/fonts/NOTICE.txt`.
