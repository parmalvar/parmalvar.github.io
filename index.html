Concept Drift in Malware Detection

June 2026 – Present

Supervised by Dr. Mohammad Dakhilalian and Dr. Mojtaba Khalili

I am studying concept drift in machine-learning-based malware detection, with a focus on how detection performance degrades as malware characteristics and data distributions evolve over time.

My current work centers on reviewing and presenting research on malware detection and drift-aware learning, including static and deep-learning-based detection, temporal distribution shifts, drift detection, and model adaptation. Featured Projects

I

Adversarial Robustness of Flow-Based Network Intrusion Detection

2026 · Adversarial ML · Network Intrusion Detection · CIC-IDS2017

Implemented and evaluated FGSM and PGD adversarial attacks against a CIC-IDS2017 flow-based MLP network intrusion detection system, including a padding/delay mutability mask that freezes immutable features and restricts selected traffic statistics to increase-only changes. Unconstrained PGD reached an 82% ASR; the mutability mask reduced ASR to 46%, constrained examples transferred to a random forest at 61% ASR, and adversarial training reduced constrained ASR to 8% with clean F1 of 0.957.

Repository Report

II

RSA-CRT Side-Channel Analysis

2026 · Applied Cryptography · Side-Channel Analysis · RSA-CRT

Developed a reproducible simulated Simple Power Analysis (SPA) framework for RSA-CRT, implementing square-and-multiply leakage, dp recovery, and modulus factorization via GCD. Unprotected RSA-CRT yielded 100% exact dp recovery in 1024-bit trials, while the Montgomery ladder and dummy multiplication reduced exact recovery to 0%.

Repository Report

III

Game-Theoretic IDS Sampling

2025–2026 · Network Security · Game Theory · Simulation

Extended a theoretical IDS-sampling model into a reproducible simulation framework for allocating limited sampling budgets using max-flow/min-cut, with uniform and randomized baselines. In seeded Monte Carlo experiments, on a 3×3 grid at Bs/MF ≈ 0.30, min-cut allocation achieved detection probability 0.300 vs 0.161 for uniform sampling, an 87% relative improvement.

Earlier theoretical work: Game-Theoretic Network IDS

Repository Report
